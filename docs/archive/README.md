# docs/archive

Historical documents — briefs, handoffs, and trackers whose work is **done** (or migrated
elsewhere). Kept for the record; nothing here is binding or current.

- `BACKLOG.md` — the old running tracker. Superseded 2026-08-04 by
  [GitHub Issues](https://github.com/curtisrutland/just-my-website/issues).
- `notes.md` — early idea scratchpad (all items resolved or migrated to issues).
- `HANDOFF-CODE.md` / `HANDOFF-DESIGN.md` — the original bootstrap briefs for the macro
  module and the design reference.
- `*-design-brief.md` / `shopping-design-handoff.md` / `panel-code-brief.md` /
  `panel-recipes-sender-brief.md` — per-module Claude Design / build briefs, all shipped.
  Still useful as **templates** when scoping a new module (see `docs/MODULE-RUNBOOK.md`).
- `batches-brief.md` / `ingredient-registry-brief.md` — macros-extension scoping briefs,
  both built and live.
- `design-reference/` — design-phase reference notes.
- `activity-model.md` — scoping draft for a self-recording "activity" module. **Rejected**
  (2026-08-04): it was scoped from a different approach to ride capture, superseded by the
  rides module.

Living reference stays in `docs/`: `ARCHITECTURE.md`, `CONVENTIONS.md`, `MODULE-RUNBOOK.md`,
`UI-CONTRACT.md`, `panel-contract.md` (binding), and the per-module `*-model.md` specs.
